The Android chat screen needs to behave exactly like WhatsApp with gesture navigation.

Current issue

The message composer extends into or sits flush against the Android gesture navigation area. I want a dedicated full-width background strip below the composer (typically the bottom safe area) so the entire chat UI sits above it, exactly like WhatsApp.

Desired behavior
The composer should end above the gesture navigation area.
The bottom safe area should be rendered as a separate full-width view using the app background color (colors.background, currently #09090B).
The gesture navigation area should never contain any part of the composer.
When the keyboard opens, the composer and messages should move together while the safe-area strip remains below them.
This should work on Android edge-to-edge devices.
Preserve the existing iOS behavior.
Requirements
Move ownership of the bottom safe-area inset from ChatInput to the parent chat screen.
ChatInput should only have its normal internal padding (around 8px). It should not use insets.bottom.
In CommunityChat, render a dedicated bottom spacer:
<View
  style={{
    height: insets.bottom,
    backgroundColor: colors.background,
  }}
/>

below the composer.

Ensure KeyboardControllerAvoidingView only moves the chat content and does not cause the composer to overlap the gesture navigation area.
Verify the root container, keyboard container, and bottom spacer all share the same background color.
If the current KeyboardControllerAvoidingView configuration prevents this layout, refactor it so the hierarchy becomes:
Root
 ├── Header
 ├── Keyboard container
 │     ├── Messages
 │     ├── Typing indicator
 │     └── Composer
 └── Bottom safe-area spacer

instead of placing the safe area inside the composer.

Goal

Make the Android chat screen visually identical to WhatsApp:

composer above the gesture area
dedicated black bottom strip
smooth keyboard animation
no overlap
no white gap
no hardcoded heights; use useSafeAreaInsets() correctly

Before making changes, inspect the existing layout and explain why the current hierarchy prevents the WhatsApp-style layout. Then implement the minimal changes necessary without affecting the rest of the chat UI.
